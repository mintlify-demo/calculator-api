## Versions

| Version | Shape | Use it when |
| --- | --- | --- |
| **v1** | `POST /v1/add`, `/v1/subtract`, `/v1/multiply`, `/v1/divide` with `{a, b}` | You have exactly two numbers |
| **v2** | `POST /v2/calculate` with `{operation, operands}` | You have two or more numbers, or want one endpoint |

<Note>
  Both versions are supported. v1 is not deprecated.
</Note>
